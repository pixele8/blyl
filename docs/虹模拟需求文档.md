# 虹模拟玻璃窑炉模拟应用需求文档

## 1. 概述
虹模拟是一款面向玻璃制造企业、研究机构及设备供应商的离线玻璃窑炉模拟应用。系统通过专业的物理参数建模与可视化交互，帮助用户在无网络环境下进行工艺参数分析、优化与培训。应用采用 HTML/CSS/JavaScript/TypeScript 技术栈构建，提供模块化、可扩展的前端架构，为后续引入高级数值模拟、三维可视化等能力奠定基础。

## 2. 目标与范围
- **离线运行**：所有资源本地部署，不依赖云端服务，可在工厂、实验室等网络受限场景稳定运行。
- **参数化模拟**：支持对窑炉结构、燃烧系统、电加热系统、投料系统及玻璃成分等关键参数的调整。
- **专业级分析能力**：通过可视化界面呈现关键参数、状态概览与趋势，为决策提供依据。
- **可扩展性**：采用组件化、模块化架构，便于接入更多物理模型、数据导入导出、报表生成等高级功能。

## 3. 用户画像与场景
| 用户角色 | 主要需求 | 使用场景 |
| --- | --- | --- |
| 工艺工程师 | 调参、对比工况、优化玻璃品质 | 日常生产调整、试制评估 |
| 设备工程师 | 评估燃烧、电极布置方案 | 设计阶段方案比选 |
| 研究人员 | 验证新型玻璃配方与工艺 | 研发项目实验、论文研究 |
| 培训讲师 | 演示窑炉工作机制、教学 | 新员工培训、课堂演示 |

## 4. 功能需求
### 4.1 基础模块
1. **参数管理**
   - 调整燃枪位置（水平/垂直坐标、角度）。
   - 设置燃枪火焰大小（功率/热流密度）。
   - 调节玻璃液面高度。
   - 配置玻璃料成分（SiO₂、Na₂O、CaO、Al₂O₃ 等自定义组分及百分比约束）。
   - 定义电极位置（多电极坐标）、电压、电流。
   - 指定投料口数量、位置及尺寸。
   - 配置池炉各分区尺寸（长度、宽度、深度、液面高度）。
   - 管理炉衬层材料、厚度及热工性能参数。
2. **状态概览面板**
   - 以结构示意图展示窑炉主要部件及参数分布。
   - 显示当前参数组合的汇总指标（热负荷、理论能耗、料面覆盖率等占位数据，可后续接入真实模型）。
3. **方案管理**
   - 保存、加载本地方案。
   - 支持对比两个方案的参数差异。
4. **数据导入导出**（后续扩展）
   - CSV/JSON 导入导出参数配置。
5. **模拟核心（后续迭代）**
   - 接入 CFD 或热传导模型，输出温度场、流场等专业数据。

### 4.2 交互与可视化
- 参数调整采用滑块、数字输入、下拉选择等复合控件，提供实时验证与单位提示。
- 玻璃料成分采用可编辑列表，动态校验总和为 100%。
- 状态可视化升级为可交互 3D 视图，支持旋转/缩放浏览炉体、炉衬层与设备并直接编辑位置与数量。
- 提供日志或事件流，记录关键参数变更。

### 4.3 系统设置
- 支持单位制切换（公制/英制，后续扩展）。
- 支持多语言界面（中文为默认，后续扩展英文等）。

## 5. 非功能需求
- **性能**：在中等配置离线电脑上实时响应参数调整，渲染延迟低于 100ms。
- **可靠性**：本地存储方案与配置，防止断电或软件崩溃造成数据丢失。
- **可维护性**：代码使用模块化 TypeScript，具备严格的类型定义与注释。
- **可扩展性**：采用插件化架构，允许新增模块（如能量平衡、排放评估、智能优化）。
- **安全性**：离线运行，无需联网，保证生产工艺数据保密。

## 6. 系统架构概览
- **展示层**：采用响应式布局的前端界面，包含导航、参数面板、模拟视图、状态面板。
- **逻辑层**：使用状态管理模块统一维护参数，提供事件机制通知 UI 更新。
- **数据层**：使用结构化对象描述窑炉参数，预留本地存储、文件读写接口。
- **模拟引擎接口**：预留标准化接口（TypeScript 接口定义），便于挂接真实物理模型。

## 7. 功能分期
1. **里程碑 M1（当前阶段）**
   - 建立项目骨架、编码规范、构建流程。
   - 实现参数面板、三维状态概览的基础交互、设备增删与数据可视化占位。
2. **里程碑 M2**
   - 引入本地方案管理（存储、加载、对比）。
   - 加入能量平衡的基础计算模块。
3. **里程碑 M3**
   - 对接高级模拟引擎、生成报告与可打印输出。

## 8. UI 设计原则
- 工业风格配色（深色背景 + 高对比度强调色）。
- 重要参数提供单位、范围提示，并支持键盘输入精调。
- 采用面板式布局，确保在 1366×768 及以上分辨率下展示完整信息。

## 9. 风险与假设
- 真实物理模型需与工厂现有数据校准，当前阶段提供示意与扩展接口。
- 离线环境对硬件要求较高，需提前确认运行设备性能。
- 项目需考虑与企业 IT 环境的兼容性（Windows 桌面浏览器、离线打包）。

## 10. 验收标准
- 应用可在现代浏览器中离线加载并运行。
- 用户可通过界面调整所有核心参数，并实时查看状态面板更新。
- 代码通过基本的 TypeScript 编译检查，项目结构符合扩展要求。
- 文档完整，包含需求、架构说明与后续扩展建议。
