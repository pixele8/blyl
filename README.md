# 虹模拟（Hong Simulator）

虹模拟是一款面向玻璃制造行业的离线窑炉模拟前端原型，采用 HTML、CSS、JavaScript 与 TypeScript 实现。该仓库当前提供：

- 《虹模拟玻璃窑炉模拟应用需求文档》，详细描述系统目标与功能规划。
- 基础前端界面，支持燃枪、玻璃液面、电极、投料口等关键参数与数量的交互式调节。
- 玻璃配方编辑、事件日志与状态指标展示，并内置可调步长的热工模拟引擎雏形。
- 炉池分区尺寸、液面深度、炉衬层材料等结构化配置面板，实现工业运行参数与结构的一体化管理。

## 本地开发

仓库已经包含可直接运行的 `dist/main.js`，无需额外工具即可在浏览器中双击 `index.html` 离线体验。

若需修改源码，可执行以下步骤重新打包：

```bash
npm install
npm run bundle
```

命令会调用 [esbuild](https://esbuild.github.io/) 将 TypeScript 源码及 three.js 依赖打包成单一脚本，方便在 `file://` 环境下运行。

### 前端界面速览

- **窑炉参数**：滑动条与数字输入同步，实时刷新状态指标与事件日志，覆盖燃枪/电极/投料口数量与尺寸。
- **玻璃成分**：调整各氧化物比例，校验总和并触发快照。
- **结构配置**：编辑熔化区、澄清区、工作池等分区的长宽深与炉衬层材料、厚度、导热系数。
- **模拟控制**：设置时间步长、环境温度等参数，启动/暂停/重置离线模拟并查看时间序列。
- **状态概览**：三维视图提供炉膛、炉衬与设备的空间化布局，可自由旋转缩放，指标卡展示热负荷、电功率、熔化深度、稳定性。
- **三维编辑**：通过叠加的 3D 编辑面板，单击选择分区、炉衬层或设备并调整参数，可在视图中直接新增、定位和移除燃枪、电极、投料口。
- **事件记录**：记录参数调整、模拟提示等关键事件，便于追踪。

```

├── styles/                  # 样式文件
├── index.html               # 离线单页应用入口
```

### 三维编辑交互

1. 在“状态概览”面板中，右侧浮层显示当前设备数量与操作按钮，可切换“新增燃枪/电极/投料口”模式。
2. 进入新增模式后，在三维视图中点击目标区域即可放置设备：燃枪自动吸附到炉池两侧，电极与投料口则按点击坐标定位。
3. 单击任意对象可调出对应属性面板，支持修改尺寸、位置、材料、电气参数等配置，并可在面板底部删除设备。
4. 若在移动端或窄屏设备访问，三维编辑面板自动收纳至视图下方，保持完整功能。
